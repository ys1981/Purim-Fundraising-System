# מערכת ניהול מגבית פורים

יישום שולחני ל-Windows לניהול קמפיין גיוס תרומות בפורים. הפרויקט נבנה בהדרגה לפי מסמך הדרישות המלא.

## מצב הפיתוח

זהו שלד פיתוח ראשוני בלבד, ולא גרסה מלאה לשימוש מבצעי. המודולים יתווספו וייבדקו בשלבים. אין להשתמש בנתוני תורמים אמיתיים עד להשלמת אבטחה, גיבויים ובדיקות.

## הפעלה

דרישות: Node.js בגרסת LTS.

```bash
npm install
npm start
```

## בניית מתקין Windows

```bash
npm run build:win
```

## עקרונות

- עבודה מקומית ללא תלות בשירותי ענן בזמן ריצה.
- ממשק עברי מלא וכיווניות RTL.
- הפרדה בין תהליך Electron לממשק באמצעות preload מוגבל.
- שמירה מקומית וגיבוי לפני פעולות מסוכנות.

## תכנון

היישום יפותח במודולים: תורמים, בחורים, אזורים ורחובות, דלת-דלת, קבוצות פורים, קבלת פנים, דוחות, הדפסות, מפות אופליין, משתמשים והרשאות, גיבויים וסנכרון רשת מקומית.
