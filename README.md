# מערכת מגבית פורים

יישום Electron מקומי בעברית (RTL) לניהול קמפיין מגבית פורים.

## הפעלה
דרישות: Windows 10/11 ו-Node.js 22 LTS.
```powershell
npm install
npm start
```

בניית מתקין Windows:
```powershell
npm run build:win
```

## יכולות שמומשו בקוד
- ממשק עברי RTL, יצירת מנהל ראשי בהפעלה ראשונה, התחברות ונעילה לאחר חוסר פעילות.
- מסד SQLite מקומי עם WAL, טבלאות לתורמים, תרומות, בחורים, שיעורים, שנים, מועדים, רחובות, כינויים, מסלולים, זוגות, קבוצות, יומנים וגיבויים.
- כרטיס תורם, רישום תרומה והיסטוריה, ארכיון תורמים ושחזורם.
- עמדת קבלת פנים: איתור לפי קוד תורם, הצגת כתובת וסכום מצטבר, ורישום תרומה עם חסימת לחיצות כפולות.
- רשימת התרמה טלפונית עם סטטוס שיחה והחזרת תורם לרשימת הפעילים.
- יצירת קבוצות פורים, שיוך בחורים ותורמים וספירת חברים ותורמים.
- יצירת שנות קמפיין, ניהול רחובות וכינויים, מסלולים, טווחי בתים ושיבוץ זוגות.
- הרשאות לפי תפקיד ובדיקת הרשאה בתהליך הראשי של Electron עבור ערוצים מוגנים.
- ייבוא תורמים מקובץ CSV תואם Excel עם כותרות בעברית, בדיקת שדות חובה וזיהוי כפילויות; כל הייבוא מתבצע בעסקה אחת ונוצר גיבוי לפניו.\n- ייצוא תורמים לקובץ CSV UTF-8 הנפתח ב-Excel והורדת תבנית ייבוא מוכנה. הייבוא/ייצוא בשלב זה מתייחסים למאגר התורמים בלבד ואינם קובץ XLSX רב-גיליונות.\n- גיבוי JSON מקומי אוטומטי, גיבוי לפני שחזור, ייצוא/שחזור ובדיקות תקינות בסיסיות.
- גיבוי חי חד-כיווני לתיקייה משותפת ברשת המקומית: בוחרים תיקייה מתוך ההגדרות, והמערכת מעדכנת בה את הקובץ `Purim-Live-Backup.json` אחרי שמירות. ההעתקה נעשית דרך קובץ זמני והחלפה, ושגיאות יעד מוצגות בהגדרות.
- בדיקות אוטומטיות ו-GitHub Actions לבדיקת קוד ולבניית מתקין Windows.

## הגדרת גיבוי למחשב נוסף
1. במחשב הגיבוי יש ליצור תיקייה ולשתף אותה ברשת המקומית עם הרשאת כתיבה למשתמש Windows שמפעיל את התוכנה במחשב הראשי.
2. במחשב הראשי לפתוח את התוכנה ולהיכנס ל"הגדרות והדרכה".
3. באזור "גיבוי חי למחשב נוסף ברשת המקומית" לבחור את התיקייה המשותפת. ב-Windows אפשר לבחור תיקייה דרך נתיב רשת כגון `\\COMPUTER\Share\PurimBackup`.
4. לוודא שמוצגת הודעת הצלחה. הקובץ `Purim-Live-Backup.json` ייווצר בתיקייה ויתעדכן לאחר כל שמירה.
5. אם המחשב השני או הרשת אינם זמינים, הגיבוי המקומי ממשיך לפעול; מצב הגיבוי יציג את שגיאת ההעתקה האחרונה.

**חשוב:** זהו גיבוי חד-כיווני מהמחשב הראשי אל התיקייה המשותפת. הוא אינו מאפשר עבודה בו-זמנית משני מחשבים ואינו ממזג שינויים חזרה למחשב הראשי. אין לפתוח את קובץ הגיבוי ולערוך אותו בזמן שהתוכנה פועלת.

## מגבלות שעדיין דורשות פיתוח ובדיקות
הגרסה אינה מאושרת עדיין לעבודה מבצעית עם נתוני אמת. נדרשים אימות מלא של תהליכי עבודה על Windows, בדיקות שחזור מקצה לקצה ובדיקת גיבוי דרך שיתוף רשת אמיתי. עדיין לא הושלמו: סנכרון דו-כיווני וריבוי עמדות, שירות רשת עצמאי, מאגר כתובות ארצי מאומת, מפות אופליין, מנוע שיבוץ ואיזון מתקדם, יבוא Excel מלא, דוחות מתקדמים ועורך הדפסות. אין להציג יכולות אלה כמושלמות לפני מימוש ובדיקות ייעודיות.
