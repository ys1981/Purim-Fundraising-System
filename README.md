# מערכת מגבית פורים
יישום Electron מקומי בעברית לניהול קמפיין מגבית פורים.

## הפעלה
דרישות: Windows 10/11 ו-Node.js 22 LTS.
```powershell
npm install
npm start
```
בניית מתקין:
```powershell
npm run build:win
```

## מה נכלל בבסיס הנוכחי
- ממשק RTL, מסך כניסה, נעילה לאחר חוסר פעילות.
- מסד SQLite עם WAL, טבלאות לתורמים, תרומות, בחורים, שיעורים, שנים, מועדים, רחובות, כינויים, מסלולים, זוגות, קבוצות, משימות, יומנים, תבניות, גיבויים ושכבות מפה.
- כרטיס תורם מורחב, רישום תרומה והיסטוריה, כרטיס בחור בסיסי.
- רשימת התרמה טלפונית נפרדת עם סטטוס שיחה, מתקשר והחזרה לרשימת הפעילים.
- יצירת קבוצות פורים, שיוך אזור ועיר וספירת חברים ותורמים.
- תפקידי משתמש מוכנים ובדיקת הרשאות ב-main process עבור פעולות מרכזיות.
- יצירת שנת קמפיין ומסלולים בסיסיים.
- ייצוא/שחזור JSON עם גיבוי לפני שחזור, בדיקת תקינות SQLite ויומן פעולות.
- בדיקות אוטומטיות בסיסיות ו-GitHub Actions לבניית Windows.

## מגבלות שחשוב להכיר
הגרסה עדיין אינה מוכנה לעבודה מבצעית עם נתוני אמת. אין עדיין אשף יצירת מנהל ראשי, הרשאות מפורטות מלאות, הצפנת מסד הנתונים במנוחה, שירות Windows עצמאי לרשת, סנכרון מארח/אורח/גיבוי חי, מאגר כתובות ארצי ומפות אופליין, מנוע שיבוץ מלא, חלוקה אוטומטית ואיזון קבוצות, תהליכי קבלת פנים, עמדת מתקשר מלאה וחלוקה בין מתקשרים, מיזוג כפילויות, דוחות מתקדמים ועורך הדפסות. אין להציג יכולת זו כמושלמת לפני מימוש ובדיקות ייעודיות.
