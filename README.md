# מערכת מגבית פורים

יישום Electron מקומי בעברית (RTL) לניהול קמפיין מגבית פורים.

## הפעלה
דרישות: Windows 10/11 ו-Node.js 22 LTS.
```powershell
npm install
npm start
```

בניית מתקין Windows:
```powershell
npm run build:win
```

## יכולות שמומשו בקוד
- ממשק עברי RTL, יצירת מנהל ראשי בהפעלה ראשונה, התחברות ונעילה לאחר חוסר פעילות.
- מסד SQLite מקומי עם WAL וטבלאות לתורמים, תרומות, בחורים, שיעורים, שנים, מועדים, רחובות, כינויים, מסלולים, זוגות, קבוצות, יומנים וגיבויים.
- כרטיס תורם, רישום תרומה והיסטוריה, ארכיון תורמים ושחזורם.
- עמדת קבלת פנים לאיתור תורם לפי קוד, הצגת פרטי כתובת ורישום תרומה.
- רשימת התרמה טלפונית עם סטטוס שיחה.
- יצירת קבוצות פורים ושיוך בחורים ותורמים; ניהול רחובות, מסלולים, טווחי בתים ושיבוץ זוגות.
- הרשאות לפי תפקיד ובדיקת הרשאה בתהליך הראשי של Electron.
- ייבוא וייצוא CSV לתורמים, בחורים ותרומות, כולל תבניות CSV.
- ייבוא וייצוא של חוברת Excel אחת בפורמט XLSX עם שלושה גיליונות: תורמים, בחורים ותרומות. הייבוא מבצע גיבוי לפניו, בדיקות כפילויות וייבוא בעסקה אחת; שגיאה מבטלת את כל העסקה.
- גיבוי JSON מקומי אוטומטי, גיבוי לפני שחזור, ייצוא ושחזור נתונים.
- גיבוי חד-כיווני לתיקייה משותפת ברשת המקומית. הקובץ `Purim-Live-Backup.json` מתעדכן לאחר שמירות באמצעות קובץ זמני והחלפה אטומית ככל שמערכת הקבצים מאפשרת.
- בדיקות אוטומטיות ו-GitHub Actions לבדיקת קוד ולבניית מתקין Windows.

## הגדרת גיבוי למחשב נוסף
1. במחשב היעד יש ליצור תיקייה ולשתף אותה ברשת המקומית עם הרשאת כתיבה למשתמש Windows שמפעיל את התוכנה במחשב הראשי.
2. במחשב הראשי לפתוח את התוכנה ולהיכנס ל"הגדרות והדרכה".
3. באזור "גיבוי חי למחשב נוסף ברשת המקומית" לבחור את התיקייה המשותפת. ב-Windows ניתן לבחור נתיב רשת כגון `\\COMPUTER\Share\PurimBackup`.
4. לוודא שמוצגת הודעת הצלחה ושהקובץ `Purim-Live-Backup.json` נוצר בתיקייה.
5. אם הרשת או המחשב השני אינם זמינים, הגיבוי המקומי ממשיך לפעול; מצב הגיבוי מציג את שגיאת ההעתקה האחרונה.

**חשוב:** מדובר בגיבוי חד-כיווני מהמחשב הראשי אל התיקייה המשותפת. הוא אינו מאפשר עבודה בו-זמנית משני מחשבים ואינו ממזג שינויים חזרה למחשב הראשי. אין לערוך את קובץ הגיבוי ידנית בזמן שהתוכנה פועלת.
